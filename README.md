# Kinbir for iPhone

Amharic voiceovers in your own voice. Write Amharic, or paste English or a link, and Kinbir
writes the script and reads it aloud in a voice cloned from you.

- Swift / SwiftUI, iOS 17+, no third-party runtime dependencies.
- A thin client for the Kinbir server at `https://api.kinbir.com`.
- The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from
  `project.yml`. Do not commit `.xcodeproj`.
- All builds run on GitHub Actions macOS runners. No local Mac required.

## Workflows

| Workflow | Trigger | What it does |
|----------|---------|--------------|
| `ci.yml` | every push (except docs-only) | unsigned `Kinbir.ipa` (run artifact, 30 days), unit tests, end-to-end UI tests, live server check |
| `testflight.yml` | manual only (needs the paid-account secrets) | fastlane `beta`: signing, build, upload to TestFlight |

## Tests

- `Tests/`: unit tests for the logic (request building, decoding real server answers, error
  wording, text detection, formatters).
- `UITests/`: end-to-end tests that launch the app with its built-in mock server
  (`-uiTestMock`) and drive the real screens from Welcome to a finished voiceover.
- `scripts/live_smoke.py`: checks the real server's free public endpoints still answer in
  the shape the app expects. Never signs in, never spends credits.

## Scripts

- `scripts/make_icon.py`: regenerates the app icon (Python 3 stdlib only).
